# DataFlow version history

Latest amendment: [V1.2.A1 — Data Streams batch job audit](versions/V1.2.A1/README.md).

- [V1.1.0](versions/V1.1.0/CHANGELOG_V1.1.0.md): 25-entry cleaning logs, full CSV and print exports, table previews and dormant analysis.
- [V1.2.0](versions/V1.2.0/CHANGELOG_V1.2.0.md): retailer/store setup, service types, reusable ordered rules, sample uploads, per-rule/section previews and final-example export.
- [V1.2.A1](versions/V1.2.A1/CHANGELOG_V1.2.A1.md): one batch per retailer/week, execution timing audits, approval/cancellation/reprocessing, three-attempt failure cancellation, error codes and deletion of successfully replaced jobs. Cancelling a replacement preserves the previous job.

Enhancements use V1.1.0, V1.2.0, etc. Amendments use V1.1.A1, V1.2.A1, etc. Each release starts from the latest enhancement and amendments. Source snapshots exclude databases, uploaded samples, credentials and installed dependencies.

Open the latest version folder and follow its README for Windows setup and local execution.
